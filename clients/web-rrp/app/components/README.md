# components/

Put **shared, cross-feature** components here (e.g. a generic `PageShell`,
`EmptyState`, `ConfirmDialog`).

Per-feature components live inside `features/<name>/components/` (e.g.
`features/auth/components/`).

Copy shadcn-generated primitives into here as needed — use the existing
`packages/design` workspace package for anything already centralized
(buttons, inputs, dialogs, etc.).
